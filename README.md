# 💱 Conversor de Moedas

Este projeto é um conversor de moedas simples e funcional, desenvolvido com HTML, CSS e JavaScript puro. Ele permite converter valores de **Real Brasileiro (BRL)** para outras moedas: **Dólar Americano (USD)**, **Euro (EUR)**, **Libra Esterlina (GBP)** e **Bitcoin (BTC)**.

## 🚀 Tecnologias Utilizadas

- **HTML5** - estrutura da página
- **CSS3** - estilização responsiva e moderna
- **JavaScript (Vanilla)** - lógica de conversão e manipulação DOM
- **Google Fonts** - tipografia com a fonte Roboto

---

## 📦 Funcionalidades

✅ Conversão de valores de Real para:

- Dólar Americano
- Euro
- Libra Esterlina
- Bitcoin

✅ Atualização dinâmica de bandeiras e nomes conforme a moeda escolhida  
✅ Interface limpa e responsiva  
✅ Valores simulados (cotações fixas para fins didáticos)

---

## 🧠 Como Funciona

- O usuário digita um valor em reais.
- Seleciona a moeda de destino.
- Ao clicar em **Converter**, o valor convertido é exibido ao lado com a bandeira correspondente.
- A cotação utilizada é fictícia e definida no arquivo `scripts.js`.
